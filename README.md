# MathLab

This repository contains research papers and verification materials by Chengyi Fang. The first independently reproducible deposit is a collection of 501,501 root isolations for the polynomials counting set partitions by blocks of size at least four. It establishes simple negative roots and strict interlacing across one, two, three and four rows throughout rows 4 to 2004.

[Exact root intervals, verifier and instructions](certificates/partitions) · [Source of the prediction algorithm](snapshot/research/partitions/bracket_interlacing.py) · [Open problem](https://www.symmetricfunctions.com/realRootedOpenProblems.htm) · [Licensing](RIGHTS.md)

AI systems performed the mathematics, programming and writing. Chengyi Fang initiated and financed the work, set its goals and supervised the project; he has not independently checked any part of the proof.
