Find an explicit, verifiable near-zero edge cutoff for the threshold-4 partition polynomials. We have proved all sufficiently large rows are real and interlace but the bound N is unknown; exact computation covers 4<=n<=2000. We need an infinite-range *effective* sign certificate, rather than another eventual argument. Locally we are addressing the far edge by interval evaluation of polynomial-in-1/m reciprocal coefficients. Your task is the opposite (nearest-zero) edge. Target at least the very nearest negative real zero and its location relative to the next row, for every n>=2000. If easier, produce an actual explicit bound n>=N, with a reproducible way to bridge or sharpen; avoid unenclosed asymptotic O terms. An effective one-sided zero-free interval of the correct r exp(-r) order at every n>=2000 is also substantial. Work must include proved numeric constants or narrow finite-dimensional interval tests that we can implement. Avoid claims to have run experiments.

P_n(t)=n![z^n]exp(A(z)+t B(z)), A=z+z²/2+z³/6, B=exp(z)-1-A. Let r+r²+r³/2=n. For x=c r exp(-r) the nearest zero has c -> 3/(2e). On the circle R=r+u, in v=R arg z coordinates, the exponent relative to exp(A(r))r^-n is r S_c(w)+T(v)+O(1/r), w=u+iv, S=3w²/4-c exp(w), T=w²-v² S'(w)/2, bounded v,c,u. We proved a simple saddle dominates for fixed c<3/(2e) and that an Airy transition locates the first k roots and adjacent spacing for each fixed k as n -> infinity. Now explicit constants matter.
