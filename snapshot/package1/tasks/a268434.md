# Research task: adjacent interleaving of the A268434 rows

Status checked: 2026-11-26. Suggested role: a tightly bounded secondary
investigation, after the simpler partition workflow is working.

## Definition and precise remaining question

The primary coefficient definition is [OEIS A268434](https://oeis.org/A268434):

\[
 T(0,0)=1,\qquad
 T(n,k)=T(n-1,k-1)+((n-1)^2+k^2)T(n-1,k),
\]

with entries outside `0 <= k <= n` zero. Set `P_n(x)=sum_k T(n,k)x^k` and
`theta=x*d/dx`. Then

\[
 P_0=1,\qquad P_{n+1}=(\theta^2+n^2+x)P_n.
\]

The first rows are `1`, `x`, `2x+x^2`, and `10x+10x^2+x^3`. RealRooted
[issue 1074](https://github.com/PerAlexandersson/RealRooted/issues/1074) tracks
adjacent interleaving as an open research question, with real-rootedness already
established. The current task is to find a new sufficient orbit invariant or
an exact obstruction to the adjacent-interleaving conjecture. Read the entire
issue, including later status updates, before spending model calls.

## Why this task is unusually concrete

The issue reduces the desired edge to

\[
 1+r\frac{P_n''(r)}{P_n'(r)}\ge0
\]

at each strictly negative root `r` of the actual row. The common root zero is
handled separately. For `n>=1`, put `Q_n=P_n/x`. Elementary differentiation
changes this condition to

\[
 3+r\frac{Q_n''(r)}{Q_n'(r)}\ge0.
\]

At a simple root `r_i`, logarithmic differentiation of the remaining factors
gives `Q_n''(r_i)/Q_n'(r_i)=2*sum_(h!=i)1/(r_i-r_h)`. Thus the concrete target
is a quantitative inequality on gaps between the roots of one explicitly
generated family. Preserve the indexing: `Q_1=1`, and
`Q_(n+1)=((theta+1)^2+n^2+x)Q_n` for `n>=1`.

The issue records failures of generic preservation approaches. Incorporate those
witnesses as adversarial controls instead of asking another model to prove the
same false generalization. Its exact adjacent-pair evidence reaches row 40;
later high-precision estimates are useful guidance for choosing stronger
invariants and retain their numerical status.
